RISC-V Challenge Showcase

This page presents browser-friendly versions of Tower of Hanoi and Conway's Game of Life, while the original Bash scripts remain in the repository for terminal execution.

How this is meant to be used

  • The terminal demos still live in hanoi.sh and life.sh.
  • The site is static, so GitHub Pages can host it without any server code.
  • The workflow in .github/workflows/pages.yml deploys this site automatically.
